# 文字装飾ラボ ― Discordテキストジェネレーター

Discordのメッセージ装飾（Markdown）と、特殊フォント変換（17種類）ができるブラウザツールです。

## 公開ページ
GitHub Pagesを有効にすると `https://ユーザー名.github.io/リポジトリ名/` で公開されます。

## 機能
- Markdown装飾のリアルタイムプレビュー（太字・斜体・下線・取り消し線・ネタバレ・コード・引用・見出しなど）
- Unicode特殊フォント変換（ボールド体・筆記体・ドイツ文字・丸文字・逆さ文字 など17種類）
- すべてブラウザ内で処理（外部送信なし）
